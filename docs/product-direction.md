# Product direction

PeekaPlate is developing AI-powered restaurant menu intelligence. The intended foundation is an intent-to-feedback loop: understand diner intent, connect it to ordering behavior, collect feedback, and help restaurants improve their menus and future guest experiences.

## Proposed next capabilities

1. Restaurant and menu ingestion with structured dishes, prices, ingredients, and provenance.
2. AI-assisted insights with traceable evidence and restaurant review before action.
3. Consent-aware intent, order, and feedback capture to support a future CRM layer.
4. Dish visualization experiments using 3D assets and AR, with quality, cost, and device compatibility evaluated before rollout.

These are planning directions. This repository currently contains the website and pilot intake flow. Add application modules as validated requirements emerge rather than scaffolding unused services now.
